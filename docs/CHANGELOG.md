## [Unreleased] - 2026-08-09

### 修正

- 手機版導覽面板在 `hidden` 狀態仍被 CSS 強制顯示，造成 01–04 常駐遮住頁面。
- 導覽驗收新增面板實際顯示狀態、語言選單開關、三語入口與收合後不佔版面的檢查。
- Headless Chrome 檢查支援由環境指定瀏覽器，保留乾淨機器可重跑性。

### 內容

- 重寫英文、日文與繁體中文的 Hero、Vision、Method、Join 主要文案，改用直接、具體的產品工作室語氣。

### 工程

- 將設計 token 漂移檢查移入 repo，移除對機器外部腳本的隱藏依賴。
